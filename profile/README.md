## Toasteez Studio

Small, self-hosted tools from [Toasteez Limited](https://toasteez.com), with the source published.

### Projects

- **[up-airquality](https://github.com/ToasteezStudio/up-airquality)**: use Ubiquiti's UP-AirQuality sensor without a UniFi Protect console. Live dashboard, Prometheus metrics, TimescaleDB history, multiple sensors, and Home Assistant via MQTT discovery.
  `brew install toasteezstudio/tap/up-airquality`

Our tools are free for personal and non-commercial use. For commercial use, get in touch via [toasteez.com](https://toasteez.com).
